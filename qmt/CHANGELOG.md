# CHANGELOG — qmt（A 股 ETF 期权卖方策略）

版本 = 文件名 `ashare_put_vX_Y.py` + 文件内 `BUILD`。改脚本不覆盖旧版：新版另存新文件，旧版移入
`archive/`。以下变更依据各版本文件头注释与 `selftest/` 覆盖点整理（2026-11-22 首次入库时回溯补齐）。

## v5_4 — 2026-11-22（BUILD=20261122-1610）首处策略行为改动

- 新增 `MAX_PER_WAVE_PER_UNDL`（默认 1，0=关）：**同一标的一浪最多开 1 张**。
  一浪 = 一次持仓周期（空仓开仓 → 再次空仓）；持仓期间不再被 setup 重新数到 9 的
  「新周期」放行。平仓归零后的新信号算下一浪，不拦。
- 动因：v5_2 回测里 588000 / 510300 / 510500 在 11-13 同一段下跌各开了 2 张（10:14 与 10:58 等），
  后一张 strike 更低、权利金更薄。
- 拦截日志独立一条「本浪已开 N 张（每浪/标的=1）」，与「达张数上限」分开，降噪 key `W<标的>`。
- INIT 开仓闸门行新增「每浪/标的=」生效值。

## v5_3 — 2026-11-22（零策略行为，只修显示与计数）

- 终局主行 bar 计数 +1：v5_2 的终局分支在 `S.bt['bar'] += 1` 之前 return，末根漏计（1500 行写
  bar=1204 而日终行是 1205）。抽成 `_bt_terminal()`。
- `drop=` 标签改名 `卖方%=` 并带符号：值为 `(开仓价 − 现价) / 开仓价`，对义务仓即卖方毛收益率，
  负值 = 权利金涨上去 = 卖方亏。旧写法 `drop=-94.3%` 容易被读成「跌了 94%」。

## v5_2 — 2026-11-22（日终/终局摘要）

- 每交易日只在 15:00 打一行 `[日终]`（同日多根 bar 不重复），只主行、不带收尾/口径。
- 终局（区间结束 / `is_last_bar()`）打「区间结束 + 收尾 + 口径 + 未平仓明细」，主行不带 `[日终]`。
- 终局触发条件：`is_last_bar()` 或 (`ymd >= BT_END` 且 `hm >= BT_EOD_HM`)。
- INIT 改用 `VERSION_LABEL`，不再硬编码 `'v1 start'`。

## v5_1 — 2026-11-22（日志降噪）

- 浮盈亏 / 已实现盈亏漂移不再触发 BTSUM（旧行为每 bar 一行）；成交（开/平仓数变化）、交易日变化、
  每 `BT_SUM_EVERY_N_BARS`(400) 根心跳、`force=True` 必打。
- 事件行内补 `开= / 平=` 字段。

## v5 — 记账口径与资金门

- 资金门 fail-closed：可用资金读成 0 时不再静默放行。
- 盈亏单一口径：价差并入逐笔成本，净 = 已实现 + 浮盈亏。
- DTE 强平：无行情时按内在价值 `max(0, strike − 现价)` 记账。

## v4 — 回测账本

- `MAX_ENTRIES_PER_DAY` 每日开仓上限（0 = 不限）。
- 回测自建账本：已实现 / 浮盈亏（按收盘）口径 + BTSUM 文本。

## v1 — 2026-11-21 首版

- 定位：ETF 现货算 TD 低9 → 卖虚值 put → 权利金回落止盈买平 → 到期自然行权。
